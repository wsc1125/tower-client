# Battle Bag Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在战斗 HUD 中实现游戏不停顿的 20 格背包面板，支持近战/远程武器拖拽穿脱，并为头盔、身甲、鞋子保留禁用槽位。

**Architecture:** 新建独立 `Inventory` 装配存放物品定义和纯 C# 背包模型，`BattleHUD` 单向引用该装配。UI 使用 UGUI 预制体，控制器只把模型状态投影到格子视图；拖拽视图通过明确的来源类型与索引调用模型操作，不直接修改数据。

**Tech Stack:** Unity 2022.3、C#、UGUI、TextMeshPro、NUnit EditMode、Unity MCP

## Global Constraints

- 背包固定 20 格（5×4），物品不可叠加。
- 面板采用方案 A：左侧装备区，右侧背包网格，居中略向右。
- 近战武器和远程武器槽本期可用；头盔、身甲、鞋子仅显示并禁用。
- 面板打开时不得修改 `Time.timeScale`。
- 本期不实现掉落拾取、装备属性、存档、使用、丢弃和分解。
- 物品定义使用 ScriptableObject。

```csharp
using System;
using System.Collections.Generic;

public sealed class Inventory
{
    public const int BagCapacity = 20;
    private readonly ItemDefinition[] bag = new ItemDefinition[BagCapacity];
    private readonly Dictionary<EquipmentSlotType, ItemDefinition> equipped = new();
    public event Action Changed;

    public ItemDefinition GetBagItem(int index) => IsBagIndex(index) ? bag[index] : null;
    public ItemDefinition GetEquippedItem(EquipmentSlotType slot) => equipped.TryGetValue(slot, out var item) ? item : null;
    public static bool IsSlotUsable(EquipmentSlotType slot) => slot is EquipmentSlotType.MeleeWeapon or EquipmentSlotType.RangedWeapon;

    public bool TryAdd(ItemDefinition item) { /* reject null; place in first null cell; invoke Changed once */ }
    public bool TryEquipFromBag(int bagIndex, EquipmentSlotType targetSlot) { /* validate index/item/usability/type/empty target, then move */ }
    public bool TryUnequipToBag(EquipmentSlotType slot, int bagIndex) { /* validate usable slot, equipped item, target index and emptiness, then move */ }
    public bool TrySwapInBag(int firstIndex, int secondIndex) { /* validate both indexes, swap, invoke Changed once */ }
    private static bool IsBagIndex(int index) => index >= 0 && index < BagCapacity;
}
```
