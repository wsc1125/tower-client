# 收藏展馆 · 界面原型设计

> 版本：v1（全新设计，不复用旧素材）
> 设计尺寸：1920 × 1080（16:9），面板整体等比缩放适配
> 视觉风格：科幻深色

---

## 一、设计目标

1. **比例绝对稳定**：所有元素用固定像素坐标 + 固定 16:9 设计尺寸，面板整体等比缩放。任何屏幕比例下元素相对位置不变。
2. **收集感强**：按品质分区，未获得为纯黑剪影，点亮后彩色 + 品质光效。
3. **信息清晰**：顶部总进度，左侧品质分区导航，右侧网格，底部选中详情。

## 七、交互流程

```
点击主菜单「收藏」按钮
        ↓
面板淡入（alpha 0→1，0.2s）+ 缩放（0.92→1.0，ease-out）
        ↓
默认选中「全部」分类，网格显示全部 24 件
        ↓
┌───────────────────────────────────────────┐
│ 点击品质导航 → 网格刷新为该品质的收藏品      │
│ 点击格子（已获得）→ 点亮 + 发奖 + 刷新       │
│ 点击格子（已点亮/未获得）→ 仅选中，显示详情   │
│ 点击遮罩 / 关闭按钮 → 面板淡出               │
└───────────────────────────────────────────┘
```

### 点亮反馈

1. 格子图标从灰剪影 → 彩色（0.3s 渐变）
2. 品质色光晕从中心扩散（0.4s，scale 0.5→1.5，alpha 1→0）
3. 顶部进度数字滚动更新
4. 左侧导航计数更新
5. 若达成全收集 → 弹出全收集提示窗

## 十、实现要点（供制作阶段参考）

1. **面板根节点**：`ModalRoot`（stretch 全屏）→ `Window`（1920×1080 固定尺寸，居中锚点）→ 各区域。
2. **等比缩放**：`Window` 挂 `AspectRatioPanel`（designSize = 1920×1080），按父级尺寸等比缩放，居中。
3. **网格**：`GridLayoutGroup`（cellSize 180×180，spacing 24×24，constraint = FixedColumnCount 5），外层 `ScrollRect` + `RectMask2D`。
4. **格子视图**：`CollectionSlotView` 重写，字段：`frame` / `icon` / `nameText` / `glow` / `corner`。
5. **品质导航**：`CollectionCategoryTab` 组件，字段：`background` / `accentBar` / `label` / `countText`。
6. **数据**：`CollectionService` 保持不变（已有点亮/发奖逻辑可复用），仅新增按品质筛选的查询。
7. **不新增存档字段**，复用现有 `CollectionProgress`。
